# carveregex

Carve lightweight regex statistics from stdin samples.

**Site:** https://theworker02.github.io/carveregex/

## Install / run

```bash
git clone https://github.com/theworker02/carveregex.git
cd carveregex
node src/cli.js
node --test
```
